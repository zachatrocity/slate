Slate + Obsidian

  1. Install the plugin files in your vault’s .obsidian/plugins/slate/ folder. Reload Obsidian and enable Slate under Community plugins.
  2. In Slate settings, set the server URL and private publishing token. Ask your server administrator for these values.
  3. On mobile, copy or sync the plugin files and settings using a method that supports your device, then enable Slate. Your device must be able to reach the server; connect to your VPN if your deployment requires one.
  4. Open a note. Use --- between slides, and slide_theme: graph_paper in frontmatter to choose a theme.
  5. Run Slate: Publish slides. Open the slides_url or slides_pdf property.

Local PNG/JPEG/WebP/GIF images are uploaded. Download remote images into your vault first. Note embeds, SVG, video, and reference-style images aren’t supported in this first version; the plugin reports unsupported inputs rather than publishing incomplete images.

Republishing replaces the destination of the same links, not the source note. Publish again to show edits; this is not continuous live preview. The publishing token lives in plugin settings, never the note.

Community themes must be self-contained CSS or depend only on Marp built-in themes. External fonts are blocked and fall back to installed fonts. Import related theme files individually when one depends on another.
